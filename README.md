This is my Week 1 project for Terra Hack-Club!

It is a pretty basic outline of a clicker game based around a randomly moving button all made in pygame, it includes:
  - Multiple files
  - Basic gameplay
  - Custom and modular UI system including text and buttons
  - Custom item system

It's not the most revolutionary project but I had fun making it, but it got me back into pygame
